# 🧠 Sentiment Analyzer

A simple web app that analyzes the sentiment of text input using **TextBlob** and displays whether it is **Positive**, **Negative**, or **Neutral**.

Built with [Streamlit](https://streamlit.io), this tool demonstrates the power of basic Natural Language Processing (NLP) in a user-friendly interface.

## ✨ Features

- 📝 Input any text (e.g., review, tweet, feedback)
- 📊 Instant classification as Positive, Negative, or Neutral
- 📈 Sample sentiment analysis on example data with chart
- 🔍 Built entirely with Python and no front-end coding needed

## 🛠️ Tech Stack

- Python
- Streamlit
- TextBlob (for NLP)
- pandas
